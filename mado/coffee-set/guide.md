# 晨雾 · 手冲参数卡

> 适用于「拾光咖啡 · 晨雾」手冲入门套装。  
> 本参数卡为原创示例内容，产品与参数均为虚构。

## 一套固定的起点

| 项目 | 建议值 |
| --- | --- |
| 粉量 | 15g（单人份，最多 18g） |
| 粉水比 | 1:15（总注水 225g） |
| 水温 | 91–93°C |
| 研磨 | 中细，白砂糖粗细 |
| 滤纸 | 01 号锥形，无漂白 |
| 总时长 | 约 2 分 30 秒 |

先把所有变量固定下来，连续做三天。三天之后再动参数，才知道变化来自哪里。

## 冲煮步骤

### 0:00　准备

1. 烧水，目标水温 92°C。
2. 滤纸沿接缝折好，放进滤杯，用热水淋湿并预热分享壶与杯子。
3. 称 15g 咖啡豆，磨到白砂糖粗细。
4. 倒入滤杯，轻拍杯壁让粉层平整。

### 0:00–0:30　闷蒸

从中心向外画小圈，注入 30g 水，确保所有粉都沾到水。等待 30 秒。

粉层鼓起、不再冒大泡，说明二氧化碳排得差不多了，可以继续。

### 0:30–2:00　分段注水

1. 缓慢绕圈注水到 150g。水流保持细而不断，尽量不要冲到滤纸边缘。
2. 等水位下降一半，再注水到 225g。
3. 注水时保持粉层均匀，不要在一个点持续冲。

### 2:00–2:30　收尾

滤杯滴到不再成线就取下，不要等最后一滴。轻轻摇匀分享壶，让浓度一致，再倒进两只温过的杯子。

## 想调整时，一次只改一个变量

| 想要的结果 | 调整方式 |
| --- | --- |
| 更酸、更明亮 | 研磨略粗，或水温降 1–2°C |
| 更甜、更厚 | 研磨略细，或水温升 1°C |
| 更淡 | 粉水比改为 1:16 |
| 更浓 | 粉水比改为 1:14，或粉量加到 17g |

每次只改一项，并记录结果。连续两次往同一个方向调整，再判断是否有效。

## 三种常见失败

**1. 流速太慢，超过 3 分 30 秒**  
研磨偏细，或注水时冲散了粉壁。下一杯调粗一格，注水更轻。

**2. 流速太快，1 分 30 秒就滴完**  
研磨偏粗，或粉量太少。下一杯调细一格，确认粉量是 15g。

**3. 味道发苦、发涩**  
水温过高或萃取过度。先把水温降到 90°C，再考虑调粗研磨。

## 保存

- 咖啡豆开封后密封，放在阴凉干燥处，四周内喝完。
- 不建议冷藏；反复取出会让豆子受潮。
- 滤纸保持干燥，避免和咖啡豆放在一起吸味。
